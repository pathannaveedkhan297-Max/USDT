Transformation Types

  • Translate: Changes the position of an element.
  • Rotate: Turns an element by a specified angle.
  • Scale: Changes the size of an element.
  • Skew: Slants the element along an axis.
  • 3D Rotate: Rotates an element around X, Y and Z axes.
